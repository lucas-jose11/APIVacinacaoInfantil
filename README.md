# 👶 API Vacinação Infantil

Sistema desenvolvido para auxiliar no controle da carteira de vacinação infantil, permitindo o cadastro de crianças, responsáveis e aplicações de vacinas.

## 📚 Sobre o Projeto

Este projeto foi desenvolvido como trabalho da disciplina de Programação Orientada a Objetos (POO), utilizando Java e MySQL.

O sistema funciona através de um menu em terminal, permitindo o gerenciamento das informações de vacinação de crianças cadastradas.

---

## 🚀 Funcionalidades

- ✅ Cadastro de responsáveis
- ✅ Cadastro de crianças
- ✅ Registro de aplicações de vacinas
- ✅ Consulta da carteira de vacinação
- ✅ Remoção de registros de vacinação
- ✅ Persistência de dados em banco MySQL

## ⚙️ Banco de Dados

O sistema utiliza MySQL para armazenamento dos dados.

Antes de executar o projeto:

1. Criar o banco de dados.
2. Executar os dois script SQL, um sendo o CREATE da DATABASE junto com as TABLES, e o outro sendo os INSERTS para que a DATABASE tenha dados, ambos os scripts SQL estão presentes na pasta SQL, dentro da pasta main.
3. Configurar usuário e senha na classe:

```java
DatabaseConnection.java
```
